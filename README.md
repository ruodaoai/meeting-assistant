# 会议助手（AI 参会 · 实时转写 · 纪要）

> 若道（Ruodao）桌面端功能插件的官方开源仓库。双通道实时录音转写、说话人自动识别、AI 参会发言、一键会议纪要与 Markdown 导出——让每一场会议都有记录、有结论、可追溯。

**📦 插件市场地址**：https://ruodao.com/plugin-market/items/meeting-assistant
（在若道桌面端「功能插件市场」搜索"会议助手"即可一键安装，也可以在市场页直接「下载 ZIP」拿到与本仓库一致的源码。）

## ✨ 功能总览

| 功能 | 说明 |
| --- | --- |
| 🎙️ **实时会议转写** | 麦克风 + 系统内录**双通道并行听写**，线上会议两路声音自动分离；每说一句立即上屏写入时间线，本机流式模型边说边出字 |
| 🧑‍💼 **说话人自动识别** | 内置声纹模型，会议方不同发言人自动归属（"谁在发言"面板按声纹归档，可改名、可合并）；只有麦克风时也能靠声纹区分 |
| ☁️ **云端精转写** | 本机实时出字 + 云端逐句精修（豆包 seed-asr / GLM-ASR / Whisper 等 OpenAI 兼容服务），同音字、错别字自动修正；不配置云端也能纯本机离线跑 |
| 🤖 **AI 参会发言** | 随时邀请 AI 参谋：它听了全场上下文后直接在时间线里发言；也有"催一下 AI 参会发言"的口头快捷入口与推荐话术 |
| 📝 **一键会议纪要** | 会中/会后按整场逐字稿生成结构化纪要，AI 多话题把纪要参考它审 |
| 📂 **文件转写** | 已有录音/视频直接转记录：wav / mp3 / m4a / aac / flac / ogg / wma / mp4 / mkv / mov / webm，单文件上限 500MB，可选说话人分离 |
| 💾 **导出与回放** | 每场会议的逐句录音、逐字稿、纪要可导出 Markdown；任意一句可回放录音、编辑文本、删除 |
| 🔧 **环境自检** | ffmpeg、录音设备、STT/LLM 模型一键体检，缺什么补什么 |

## 🌟 亮点

- **纯本机优先，隐私可控**：识别由 sherpa-onnx 离线完成，录音、逐句音频与逐字稿只写入本机会话目录；只有你主动开启云端转写或 AI 分析时，对应内容才会发给你自己配置的模型服务。
- **本机模型全家桶共享**：流式模型、高精度离线模型（SenseVoice / Paraformer）、标点恢复模型、说话人分离模型一次下载，会议助手 / 面试助手 / 文件转写全插件通用。
- **预热线程秒开**：进入页面就提前加载识别线程，点「开始听写」无需等模型加载。
- **断句即落盘**：每句音频单独保存（16k wav），既是回放素材，也是云端精转写的输入；转写失败自动回退本机识别文本，不丢句子。
- **说话人可维护**：识别错了能改名、能合并，越用越准。

## 📥 安装

1. 下载并安装 [若道桌面端](https://ruodao.com)。
2. 打开左侧「功能插件市场」→ 搜索 **会议助手** → 点「安装」；或在本页 [Releases](../../releases) 下载 ZIP，用市场页的「**从本地安装**」导入（不需登录）。
3. 打开插件，先点「环境自检」：按提示安装 FFmpeg、下载本机转写模型（约 20MB，支持断点续传）。
4. （可选）到「模型管理」添加云端转写模型（如 `doubao-seed-asr-2.0`、`glm-asr`、`whisper-1`），并在插件「设置 → 转写与说话人」里选择"云端增强"。

## 🚀 使用教程

### 实时会议（线上会议 / 线下会议室都适用）

1. **创建会议并准备听写**：填写会议主题、参会人（可选），点「创建会议并准备听写」。
2. **选录音通道**：
   - 线上会议：选"使用系统内录"听会议对方声音，麦克风听你自己，两路并行、自动归属说话人；
   - 线下会议：只用麦克风即可，声纹模型会自动区分不同发言人。
3. **开始听写**：每说完一句立即上屏并写入时间线；本机模型实时出字，配了云端精转写会逐句自动修正。
4. **AI 参会**：点「AI 发言」或直接说"AI，你怎么看这个方案？"，AI 会基于全场上下文发言；也可以点推荐话术一键催它。
5. **会中/会后**：任意一句可回放录音、改文本；点「生成纪要」出结构化纪要；「导出」得到 Markdown（含逐字稿与纪要），都存在你设置的会议数据目录下。

### 文件转写

把已有录音/视频拖进「文件转写」→ 选本机或云端引擎、是否分离说话人 → 转写完成自动生成一条会议记录，后续同样可以生成纪要、导出 Markdown。

### 设置建议

| 场景 | 推荐配置 |
| --- | --- |
| 追求准确率 | 转写通道选「云端增强」，模型选豆包 seed-asr / GLM-ASR |
| 隐私优先 / 无网 | 保持「本机转写」，可另外下载高精度离线模型 SenseVoice / Paraformer |
| 多人线下会议 | 打开「区分说话人」（首次会引导安装声纹模型，约 34MB） |
| 低配机器 | 关闭系统内录双通道，仅麦克风 + 声纹区分 |

## 🛠️ 二次开发：怎么改成你自己的插件

本插件**免编译**：源码即运行包，改完就能跑。目录结构：

```
├── plugin.json           # 元信息：名称、版本、UI 入口（指向 ui.json）
├── ruodao-plugin.json    # 核心：id、权限（process/network）、18 个命令的声明
├── ui.json               # 插件界面配置
├── bin/meeting-assistant.mjs  # 全部业务逻辑（纯 Node.js，~1200 行）
├── test/plugin.test.mjs  # 测试
└── docs/screenshots/     # 本页截图
```

改功能三步走：

1. **加逻辑**：在 `bin/meeting-assistant.mjs` 里加一个子命令（读参数、干活、输出 JSON 即可）。
2. **注册命令**：在 `ruodao-plugin.json` 的 `contributes.commands` 里照抄现有条目改个 id/title/args。需要联网或调子进程时，确认 `permissions` 里有 `network` / `process`。
3. **本地安装验证**：若道桌面端「功能插件市场 → 插件管理 → 从本地安装」直接选**文件夹或 ZIP**（不需登录、不进市场）。建议先把 `plugin.json` 的 `version` 加一位。

开发期更快的方式：本地安装其实就是把文件拷到 `~/.codex/plugins/codex-market/meeting-assistant/`，直接改那里的 `.mjs/.json` 再重启应用即可热迭代。

运行测试：

```bash
node test/plugin.test.mjs
```

两点注意：

- **不要硬编码 API Key**。宿主提供模型凭据注入（`modelBinding`），走官方机制才安全，你的密钥也不会进仓库。
- 想上架分享自己的改版？在市场页「插件创作」提交 ZIP 审核即可；本仓库代码可作为起点。
